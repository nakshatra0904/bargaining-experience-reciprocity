# Measurement comparison — exploratory follow-up

The planned common-price normalization check has negative concession slopes,
while the normalized-gap benchmark is positive. This observation is not the
original experience-interaction hypothesis. I record the following follow-up
before examining its seller-split results:

1. Use the same primary novice/experienced sample, controls and fixed stage.
2. Refit the common-price specification separately for the existing discovery
   and validation seller halves. No new thresholds or sample filters.
3. Report both group slopes and clustered confidence intervals in all halves,
   including any disagreement. Also estimate the all-experience common slope
   under both measures, with identical price/gap/month and continuous history
   controls.
4. Do not interpret signs under different scales as estimates of the same
   parameter. Present them as a measurement sensitivity diagnostic, not proof
   that the published study is wrong or that reciprocity has been disproved.
5. A targeted search can motivate a candidate measurement project, but cannot
   establish global novelty. The deterministic holdout was already used for
   the primary test; this follow-up remains exploratory, even if it replicates.
